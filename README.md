# Count Words in a String

**Author:** M.Likitha

## Description

This program reads a sentence and counts the number of words
present in it.

## File

count_words.c

## Concepts Used

- Character array
- String input
- String traversal
- `fgets()`
- Conditional statements
- `for` loop

## How to Run

gcc count_words.c -o count_words
./count_words

## Sample Output

Enter a sentence: C programming is interesting
Number of words: 4
